# T41 Desktop Companion

The T41 desktop companion is a user interface for the T41 ham radio.

Should be compiled to run at 600MHz to avoid system freezes on some Teensy boards.

The *T41_DC.ino.hex* file is a version of the code with CAT control disabled.
